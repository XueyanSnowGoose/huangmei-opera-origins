# 黄梅戏源流知识树

> 依据陆洪非《黄梅戏源流》(安徽文艺出版社,1985 年 9 月第 1 版)全书整理的**交互式知识树网页**。
> 从采茶歌到地方大戏——把全书三编的知识条目、出处、年表与地名志,浓缩进一个可检索、可跳转的单页。

一个纯静态页面,无后端、无构建步骤,双击 `index.html` 即可阅读,也已托管在 GitHub Pages。

---

本地查看:克隆后直接用浏览器打开 `index.html` 即可。

功能一览:

| 功能 | 说明 |
|---|---|
| 左侧目录树 | 三编 / 章 / 节三级,随阅读进度自动高亮 |
| 全文检索 | 输入「天仙配」「怀腔」「严凤英」等词,即时定位知识条目(快捷键 `Ctrl/Cmd + K`) |
| 出处印章 | 每条知识标注「第几编·第几章·第几节」,点击跳回对应章节 |

| 地名志 | 按黄梅县、安庆、望江、上海、合肥、港澳台及海外等分组 |
| 夜间模式 | 跟随系统,也可手动切换 |

## 内容与结构

全书三编,与网页目录一一对应:

1. **第一编 从采茶歌到黄梅戏** —— 探源、初步形成、从小戏到本戏、早期剧目、舞台艺术、前辈艺人。
2. **第二编 从农村「草台」到城市「花台」** —— 辛亥革命至 1949,进城、进上海、红色政权下、抗战时期、演出与形式的演变、承先启后的艺人。
3. **第三编 从民间小戏到地方大戏** —— 解放、成为「皖剧」、搬上银幕、曲折中前进、剧目推陈出新、舞台艺术变革、严凤英。

## 数据来源与准确性(请务必阅读)

- 本页所有**知识性表述均取自原书正文**,出处采用「编·章·节」标注;个别 OCR 之误已照录或按上下文径改,引号内为原书引文。
- 内容由 AI 从扫描本 OCR **总结、提炼**而来,**不保证 100% 准确**。使用本页任何内容前,**请进行人工核对**。
- 整理时曾以「整句匹配 / 成分匹配 / 覆盖率核验」三级方法对条目与原书 OCR 逐句比对(核对脚本与报告未随仓库发布,见下「仓库结构」)。
